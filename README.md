EduAssist AI is a streamlined, AI-powered document generation tool designed specifically for educators under the Department of Education (DepEd) in the Philippines. It aims to reduce the administrative burden on teachers by instantly drafting standard compliant documents, allowing them to focus more on teaching and less on paperwork.

## ✨ Key Features

* **DepEd Standard Templates:** Instantly generate compliant Daily Lesson Logs (DLL), Narrative Reports, and Activity Proposals.
* **Dynamic AI Assistant:** Powered by Google's `gemini-2.5-flash` model, allowing you to generate content from simple conversational prompts.
* **Interactive Refinement:** A built-in chat interface lets you ask the AI to tweak, expand, or rewrite specific parts of the generated document before downloading.
* **Instant Word Export:** Generates perfectly formatted Microsoft Word (`.docx`) files ready for printing or official submission.
* **Bring Your Own Key (BYOK) Architecture:** Operates with zero server-side API costs. Users securely input their own Google Gemini API key on the client side, which is injected at runtime and never stored on the server.

## 🛠️ Tech Stack

* **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS (via CDN)
* **Backend:** Python, FastAPI
* **AI Integration:** Google Generative AI SDK (`google-generativeai`)
* **Document Processing:** `docxtpl` (python-docx-template)
* **Deployment:** Vercel (Serverless Functions)

## 🔒 Security & Privacy

EduAssist AI employs a secure **Bring Your Own Key (BYOK)** model. 
* User API keys are stored exclusively in the browser's local storage.
* The key is sent securely in the request payload directly to the backend for execution.
* **Zero retention:** The server does not store, log, or cache user API keys.

## 🚀 Local Development Setup

To run this project on your local machine, follow these steps:

### Prerequisites
* Python 3.9+
* A Google Gemini API Key

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/yourusername/edu-assist-ai.git](https://github.com/yourusername/edu-assist-ai.git)
   cd edu-assist-ai
   ```

2. **Create and activate a virtual environment:**
    ```bash
    # Windows
    python -m venv venv
    venv\Scripts\activate

    # macOS/Linux
    python3 -m venv venv
    source venv/bin/activate
    ```

3. **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4. **Run the FastAPI server:**
    ```bash
    uvicorn main:app --reload
    ```

5. **Open the application:**
    Open the IP Address + port generated by unvicorn.
